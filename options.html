Recommended Firefox settings

Extensions cannot read or change these, so set them yourself in about:config (or add them to user.js):

user_pref("browser.tabs.unloadOnLowMemory", true);
user_pref("browser.sessionstore.restore_pinned_tabs_on_demand", true);

The first unloads tabs early when memory runs low. The second keeps pinned tabs from loading at startup until you click them.
